# QR-02: Plugin failure does not terminate the Gateway

**Characteristic:** Reliability / Fault Tolerance
**Business Importance:** High
**Technical Risk:** Medium

**Outcome:** When a single plugin raises an unhandled exception or times out, the Gateway completes the request according to the configured failure policy and remains available, without terminating the process or dropping other in-flight requests.

## Quality Attribute Scenario

| Part | Value |
| --- | --- |
| Source | A misbehaving plugin executed by the Plugin Manager |
| Stimulus | The plugin raises an unhandled exception or exceeds its configured timeout (default 2 s) |
| Environment | Normal operation with at least one other request in flight |
| Artifact | Gateway plugin invocation path and Plugin Manager HTTP interface |
| Response | The Gateway applies the configured failure policy (pass-through, reject, or fallback), logs the failure with the plugin identifier, and keeps serving |
| Response Measure | Gateway process stays up; ≥ 99% of unrelated in-flight requests complete normally; the failure is logged with plugin ID within 100 ms of detection |
