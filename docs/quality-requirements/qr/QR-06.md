# QR-06: Diagnose a failed request from the staging organization

**Status:** Active
**Characteristic:** Maintainability
**Sub-characteristic:** Analysability
**Business importance:** High
**Technical risk:** Medium

**Outcome:** Within five seconds of a failed request's response, a query of the staging organization returns one log point for that request carrying its `request_id`, `route`, and `failure` label; within one minute, the SLI's query returns the failure series with a P95 value.

## Scenario

### Source

The system operator diagnosing a failed request in the core task.

### Stimulus

A request fails during plugin processing, and the operator queries the staging organization.

### Environment

The staging deployment of the product, with the observability backend collecting metrics and structured logs.

### Artifact

The staging organization's log store, the SLI dashboard, and the per-request log line.

### Response

The operator retrieves the failed request's log point with its identifiers, and the SLI dashboard shows the failure series with a P95 value.

### Response Measure

Within 5 s of the failed response: one log point with `request_id`, `route`, `failure` label. Within 1 min: the SLI query returns the failure series with a P95 value.

## QRT-01

A deployed test runs core-task traffic, fails one request, and queries the staging organization for the failed request's log point and the SLI's failure series.

**Type:** Deployed
**Runs at:** Staging deployment; SLI-01

### Procedure

1. From a machine on the university network, run `scripts/check-sli.ts` against the staging deployment.
2. The script sends core-task traffic through the Gateway.
3. The script sends one request designed to fail during plugin processing.
4. The script queries the staging organization for the failed request's log point.
5. The script queries the SLI for the failure series with P95.

**Pass when:** The log point appears within 5 s carrying `request_id`, `route`, and `failure` label; the SLI query returns the failure series with a P95 value within 1 min.
