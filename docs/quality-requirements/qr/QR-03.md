# QR-03: Testability of the frontend entry point and plugin loading path

**Characteristic:** Maintainability / Testability
**Business Importance:** High
**Technical Risk:** Medium

**Outcome:** A DevOps engineer can load a new single-file plugin through the CLI and cover it with an automated integration test within one working day, by adding one plugin file and modifying at most one source file.

## Quality Attribute Scenario

| Part | Value |
| --- | --- |
| Source | A DevOps engineer using the CLI |
| Stimulus | Uploads a new single-file plugin through the CLI |
| Environment | Development environment with the documented test command; Gateway and Plugin Manager running |
| Artifact | Gateway entry point |
| Response | The Gateway accepts the plugin, the Plugin Manager discovers and executes it on the next request, and an integration test exercises the request → plugin → response flow |
| Response Measure | ≤ 1 plugin file added and ≤ 1 source file modified outside the plugin directory; integration test runs in ≤ 60 s; the new plugin is invoked on the next request without restarting the Gateway |
