# QR-01: Gateway request latency under normal load

**Characteristic:** Performance Efficiency / Time Behaviour
**Business Importance:** High
**Technical Risk:** Medium

**Outcome:** Under 50 concurrent client requests per second, the Gateway returns 95% of chat-completion responses within 500 ms of receiving the request, excluding upstream LLM provider time.

## Quality Attribute Scenario

| Part | Value |
|---|---|
| Source | An OpenAI-compatible client sending requests through the CLI or directly to the Gateway |
| Stimulus | A chat-completion request arrives at the Gateway's HTTP API |
| Environment | Normal operation, 50 concurrent requests per second, upstream LLM providers healthy |
| Artifact | Gateway request handler and plugin invocation path |
| Response | The Gateway forwards the request through the plugin chain and returns the response to the client |
| Response Measure | p95 gateway-side latency ≤ 500 ms; error rate < 0.1%; measured over a 10-minute run |
