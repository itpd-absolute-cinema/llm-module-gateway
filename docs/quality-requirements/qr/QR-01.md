# QR-01: Every enabled plugin is applied to every request and response

**Characteristic:** Functional Suitability / Functional Completeness
**Business Importance:** Medium
**Technical Risk:** Medium

**Outcome:** For every request the Gateway processes, all currently enabled plugins run exactly once in the configured order on the request path and once on the response path, and no disabled plugin runs, so the applied plugin set always matches the configured set.

## Quality Attribute Scenario

| Part | Value |
| --- | --- |
| Source | The Gateway processing an LLM request; DevOps managing plugin state through the CLI |
| Stimulus | A request arrives while some plugins are enabled and some are disabled |
| Environment | Normal operation; the plugin registry contains both enabled and disabled plugins |
| Artifact | Gateway plugin invocation and the Plugin Manager plugin registry |
| Response | The Gateway invokes every enabled plugin once on the request path and once on the response path, in the configured order; disabled plugins are never invoked |
| Response Measure | Across 100 requests with 3 enabled and 2 disabled plugins: 100/100 requests pass through all 3 enabled plugins on both paths, 0/100 requests invoke any disabled plugin, and each enabled plugin is invoked exactly once per path per request |
