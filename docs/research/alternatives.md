# Alternatives Research

Companies need a way to let employees use LLMs while applying organization-specific policies for data protection, routing, and request processing.

## Comparison Properties

1. Data control - where data is processed and who controls the infrastructure.
2. Policy enforcement – how organizational rules can be applied to LLM requests and responses.
3. Extensibility – how easily custom behavior can be added.
4. Deployment and operation – available deployment models and operational complexity.
5. Provider integrations – supported LLM providers and models.
6. Configuration isolation – whether different users or teams can have different policies.
7. Observability – how requests and policy decisions can be inspected.
8. Onboarding – how much effort is required to start using the product.
