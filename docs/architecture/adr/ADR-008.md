# ADR-008: Expose observability signals as metrics and structured logs to a self-hosted backend

**Status:** Accepted
**Containers:** Gateway, Plugin Manager
**Addresses:** FR-008, QR-06
**Decision:** The Gateway and Plugin Manager emit Prometheus metrics and structured JSON logs; a self-hosted observability backend collects them, and Grafana renders the SLI dashboards.

## Context and Problem Statement

Runtime requirements need measurable SLIs. The product must expose signals from the containers that process requests, and the backend must be self-hosted.

## Considered Options

1. **Metrics only** — rejected: the diagnosability test reads a per-request log line.
2. **Logs only** — rejected: no aggregate P95 without a metric histogram.
3. **Metrics + structured logs** — chosen: metrics for aggregates, logs for per-request diagnosis.

## Decision Outcome

Chosen option: **Option 3**. The Gateway and Plugin Manager emit Prometheus metrics and one structured log line per request. The backend is external to the product.

### Consequences

- **Good:** SLIs are computable; the per-request log line supports the diagnosability test.
- **Bad:** Two signal types to maintain; the backend is not a container.
- **Quality attributes accepted:** Maintainability / Analysability (QR-06).
