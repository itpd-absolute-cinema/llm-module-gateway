# ADR-006: Retain disabled plugin options in TOML

- **Status:** Accepted
- **Created:** 2026-10-25
- **Updated:** 2026-10-25
- **Containers:** `prototype gateway`
- **Addresses:** [FR-01](../../functional-requirements/fr/FR-01.md), [FR-02](../../functional-requirements/fr/FR-02.md), [FR-03](../../functional-requirements/fr/FR-03.md), [FR-04](../../functional-requirements/fr/FR-04.md), [FR-009](../../functional-requirements/fr/FR-009.md), [QR-05](../../quality-requirements/qr/QR-05.md)

## Context

The initial configuration implied that every listed plugin was enabled.
The feature discussion identified the missing state: a plugin must retain settings while disabled.
A source file without a configuration entry should still mean installed but disabled.
The separate-store and file-renaming options below are reconstructed comparisons.

## Considered Options

- Add an explicit enabled flag alongside each plugin's options in TOML.
- Remove entries when disabling: loses options and their ordering position unless another store is introduced.
- Keep disabled settings in a sidecar file or database: introduces a second source of configuration truth and coordinated writes.
- Rename or move disabled source files: couples import paths to status and still needs somewhere to retain settings.

## Decision Outcome

Chosen option: retain entries with `enabled = false` in the existing TOML file.
Missing flags default to true, preserving existing configurations; files without entries are disabled with empty options.
Uploads create disabled entries, and disabling preserves options and position unless an explicit ordering hint requests a move.
New entries append to the existing order unless `before` or `after` names a configured target.
Disabled entries participate in relative ordering, so enabling a plugin keeps its saved position.

## Consequences

- Reliability / Fault Tolerance ([QR-05](../../quality-requirements/qr/QR-05.md)): one configuration file can be replaced atomically without synchronizing an options sidecar.
- JSON options must be representable in TOML; `null` is rejected.
- The saved enabled flag is not a promise that the current process has loaded the plugin; activation follows [ADR-002](ADR-002.md).
- Files and TOML are not a crash-atomic transaction. Recoverable I/O failures have rollback; power-loss recovery is outside this prototype's guarantees.
