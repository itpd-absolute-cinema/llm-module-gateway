# FR-07: Gateway routes the allowed request to the configured LLM provider

**Status:** Active
**Traces to:** Main goal "Route requests to the appropriate LLM providers"
**Containers:** Gateway

## Behavior

1. The Gateway **shall**, after the plugin chain returns an allow decision, select the LLM provider endpoint based on the model name in the request.
2. The Gateway **shall** forward the request to the selected provider over HTTPS and return the provider's response to the client, preserving the response body and status code.

## Acceptance Criteria

### AC-01: Model name selects provider

Configure two providers with model prefixes `openai/` and `anthropic/`. Send a request with `model: openai/gpt-4`. The OpenAI provider mock receives the request; the Anthropic mock receives nothing.

### AC-02: Provider response is returned unchanged by routing

The provider mock returns a specific JSON body and HTTP status. The client receives exactly that body and status from the Gateway (before any response plugins are applied).
