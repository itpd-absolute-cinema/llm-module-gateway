# FR-05: DevOps deletes a plugin by name through the CLI

**Status:** Active
**Traces to:** Main goal "Support a modular, extensible plugin system"; lifecycle management of plugins
**Containers:** CLI, Gateway, Plugin Manager.

## Behavior

1. The CLI **shall**, when a DevOps engineer runs `cli plugin delete <name>`, send a delete request for that plugin name to the Gateway's plugin management API.
2. The Gateway **shall** instruct the Plugin Manager to remove the named plugin from the registry and delete its file from the Plugin Store.
3. The Gateway **shall** return an error if no plugin with that name exists, and a success response otherwise.

## Acceptance Criteria

### AC-01: Deleted plugin disappears from list and store

Upload and enable a plugin, then run `cli plugin delete <name>`. `cli plugin list` no longer contains it, and the Plugin Store directory no longer contains its file.

### AC-02: Deleting a non-existent plugin returns an error

Run `cli plugin delete does-not-exist`. The Gateway returns HTTP 404 with an error body, and the CLI exits non-zero.
